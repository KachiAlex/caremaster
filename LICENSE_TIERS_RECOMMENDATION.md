## 📊 Tiered Licensing Structure

Based on the comprehensive feature set of CareMaster, here's a recommended 4-tier licensing structure:

---

## 🥉 BASIC TIER
**Target:** Small care agencies (1-10 staff, up to 25 clients)

### Included Features:
✅ **Core Features**
- Client/Patient Management (up to 25 clients)
- Basic Caregiver Management (up to 10 staff)
- Simple appointment scheduling
- Basic care logs and documentation
- Medication tracking (basic)
- Client profile management
- Mobile app access for caregivers
- Email support (48-hour response)

- 1 Institution Admin

- 1GB storage

## 🚀 Implementation Notes

### License Tier Field in Database:
```javascript
{
  licenseKey: "LIC-XXXX-XXXX-XXXX-XXXX",
  institutionId: "...",
  plan: "professional", // basic, standard, professional, enterprise
  status: "active",
  features: {
    maxClients: 500,
    maxStaff: 200,
    maxAdmins: 10,
    storage: 100, // GB
    aiFeatures: false,
    telemedicine: true,
    pharmacy: true,
    api: "readonly", // false, readonly, full
    customBranding: false
  },
  addOns: ["sms", "whatsapp"],
  billingCycle: "monthly", // monthly, annual
  startsAt: Timestamp,
  endsAt: Timestamp,
  createdAt: Timestamp
}
```

### Feature Enforcement:
- Use license tier to enable/disable features in the UI
- Check `license.features` object in guards and components
- Show upgrade prompts when users hit limits
- Soft limits (warnings) vs hard limits (blocks)
